FAQ & Help

MagnetraPH - Bank Level Security

1. How does Bank Level Login work?

MagnetraPH uses Firebase Authentication with encrypted audit logs. Every login is verified through secure token and stored with server timestamp for compliance.

2. What is Biometric Authentication?

Biometrics uses WebAuthn standard. Your fingerprint or Face ID never leaves your device. Only a secure credential is verified. This is the same technology used by banking apps.

3. Why is my account locked for 30 seconds?

This is bank-level protection. After 5 failed attempts, the system triggers an automatic 30-second security lock to prevent brute-force attacks.

4. How does Forgot Password work?

Firebase directly sends a secure password reset link to your registered email. The link expires in 1 hour for security.

5. Is my data safe with Google Login?

Yes. Google OAuth 2.0 with Firebase verification is used. No password is stored locally. All sessions are encrypted.
